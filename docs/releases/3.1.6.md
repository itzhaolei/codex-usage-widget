## Quota Bubble v3.1.6

This macOS hotfix restores the quota refresh behavior that worked before the menu-bar percentage was introduced. Windows remains on its existing release.

### Fixed

- Runs quota synchronization every second without consulting the macOS menu event-tracking mode.
- Keeps the menu-bar percentage synchronized as a read-only view of the same shared quota store.
- Prevents menu interaction differences across Macs from leaving the widget at its startup value, such as 100%.

### Reverted

- Removes the unverified account-routing, alternate-field, and delayed failure-clearing changes from v3.1.5.
- Restores the established native usage request and snapshot behavior.

### Verified

- Passed model, store, native snapshot, and SwiftUI build tests.
- Built and inspected the macOS installer payload and Universal application binary.

### Install

- macOS: download `QuotaBubble-3.1.6-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
