## Quota Bubble v3.1.8

This macOS release adds live system-capacity information to the widget.

### Added

- Displays available storage as a compact single value using the same capacity semantics as macOS storage settings.
- Displays available runtime memory and total physical memory.
- Refreshes both values once per second alongside the existing live quota data.

### Changed

- Expands the window by two compact information rows while keeping the existing width and bottom-right version placement.

### Verified

- Passed model, store, native snapshot, shell, and SwiftUI build tests.
- Confirmed localized storage and runtime-memory formatting.

### Install

- macOS: download `QuotaBubble-3.1.8-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
