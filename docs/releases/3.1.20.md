## Quota Bubble v3.1.20

This release fixes Windows upgrades from the earlier PowerShell implementation and restores interactive color selection in the native Windows widget.

### Changed

- Windows upgrades reuse the existing native installation directory and preserve the current startup preference.
- The installer stops a running legacy `QuotaBubble.ps1` process before starting the native application.
- Legacy widget scripts, cached state, and the old snapshot helper are removed during installation.

### Fixed

- The Windows color swatches are now clickable and immediately update both the 5-hour and weekly quota bars.
- The selected color has a visible border and remains selected after the application restarts.
- Upgrading no longer leaves the pre-upgrade PowerShell widget running beside the native application.

### Verified

- Windows CI starts a simulated legacy widget, installs the graphical package, verifies that the old process and files are removed, confirms the desktop shortcut, launches the installed app, and uninstalls it.
- Windows static tests cover color button wiring, progress-bar color selection, and saved color preferences.
- The macOS installer is rebuilt from the same release tag for consistent cross-platform versioning.

### Install

- Windows: download `QuotaBubble-3.1.20-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.20-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
