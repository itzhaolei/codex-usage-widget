# Quota Bubble v4.0.0

## Changed

- Moves the macOS and Windows interface and quota logic into a shared Flutter desktop codebase.
- Reimplements the compact quota display, plan badges, color palette, sparkling progress bars, and staged recharge animation in Flutter.
- Preserves Free, Plus, Pro 5x/20x, Business/Business 5x/20x, Enterprise, and Edu plan badges across both platforms.
- Uses the same macOS-style vector symbols throughout the macOS and Windows interface.
- Keeps the macOS bundle identifier `local.codex.quota-bubble` and the existing installer filenames and installation locations for continuity with earlier releases.
- Continues to read the signed-in Codex account locally. Access tokens stay in memory and are not included in the quota cache or installation packages.
- Pauses window rendering and animation while hidden, while the macOS menu-bar percentage or Windows tray tooltip continues to update.
- Keeps the Windows taskbar entry visible and uses the macOS status-bar window level for pinned windows.

## Packaging

- Builds desktop packages with Flutter 3.47.2 and retains the graphical macOS installer and Windows Setup wizard.
- Verifies the packaged macOS application's code signature, bundle identifier, and Apple silicon/Intel architectures before publishing.
- Adds a validation-only workflow mode that retains downloadable build artifacts without publishing a release.

## Release status

Quota Bubble 4.0.0 is the current Flutter desktop release for macOS and Windows. The public website fallback and update manifest target the 4.0.0 graphical installers. The release workflows retain a validation-only mode for future builds so an installer can be reviewed before it is published.
