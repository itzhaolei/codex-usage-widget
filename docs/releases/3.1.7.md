## Quota Bubble v3.1.7

This macOS hotfix repairs installations that remained at 100% even though Codex showed the correct lower weekly quota.

### Fixed

- Prevents an incorrect snapshot with a future reset date from permanently blocking the official quota window.
- Debounces an earlier-cycle response for three seconds, then accepts it when the same official window persists.
- Invalidates the generated quota snapshot once after upgrading so affected Macs fetch fresh data immediately.
- Leaves Codex authentication, account information, window settings, theme, pin state, and color selections untouched.

### Verified

- Added a regression scenario for `100% / future reset date` recovering to `18% / official reset date`.
- Confirmed brief stale responses remain hidden during the three-second stabilization period.
- Passed model, store, native snapshot, shell, and SwiftUI build tests.

### Install

- macOS: download `QuotaBubble-3.1.7-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
