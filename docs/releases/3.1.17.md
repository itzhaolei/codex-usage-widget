## Quota Bubble v3.1.17

This release separates Windows version lookup from installer-host availability.

### Fixed

- A successful fallback version lookup no longer fails because the installer asset host rejects a follow-up `HEAD` request.
- Added a small jsDelivr-hosted update manifest between the GitHub API and GitHub Releases fallbacks.
- Checking while already up to date now needs only the version source; the installer host is contacted only when an update is actually downloaded.

### Verified

- Added Windows static coverage for the CDN manifest and removal of the installer probe.
- The Windows release workflow compiles, installs, launches, and uninstalls the generated package on a Windows runner.

### Install

- Windows: download `QuotaBubble-3.1.17-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.17-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
