## Quota Bubble v3.1.1

This macOS hotfix keeps language selection stable while the widget continues to synchronize live quota data. Windows remains on its existing release.

### Fixed

- Moves the menu-bar percentage into a native AppKit status item that updates only when the weekly percentage actually changes.
- Prevents one-second quota updates from rebuilding an open language menu.
- Pauses quota refreshes while macOS tracks application menus and resumes automatically after the menu closes.

### Install

- macOS: download `QuotaBubble-3.1.1-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
