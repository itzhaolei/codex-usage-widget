# Quota Bubble v3.1.26

This release pauses unnecessary window updates while Quota Bubble is hidden, while keeping the menu-bar or system-tray quota percentage current.

### Changed

- Closing, hiding, or minimizing the quota window pauses its countdown and detail rendering, including storage and memory refreshes.
- macOS also suspends window animations and detail updates when the window is fully covered.
- The menu-bar or tray percentage continues to follow quota changes and updates only when its displayed value changes.
- Showing the window immediately restores the latest locally available quota and account information and resumes normal updates.
- Account changes while hidden still clear the previous account's menu-bar percentage, and reopening does not replay recharge animations from the hidden period.

### Install

- macOS: download `QuotaBubble-3.1.26-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Windows: download `QuotaBubble-3.1.26-Windows-Setup.exe` and run the graphical installer.
