## Quota Bubble v3.1.11

This macOS release fixes the menu-bar percentage so it matches the 5-hour quota when that quota window is present.

### Fixed

- Shows the 5-hour remaining percentage in the macOS menu bar for accounts with a 5-hour quota window.
- Falls back to the weekly remaining percentage for weekly-only accounts.

### Verified

- Added store coverage for menu-bar percentage selection across weekly-only, active 5-hour, exhausted 5-hour, and 5-hour removal states.
- Passed model, store, native snapshot, shell, and SwiftUI build tests.

### Install

- macOS: download `QuotaBubble-3.1.11-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
