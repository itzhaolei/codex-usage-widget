## Quota Bubble v3.1.0

This macOS feature release makes weekly quota status visible directly in the menu bar and refines the widget's countdown and balance display. Windows remains on its existing release.

### Added

- Adds a compact Codex-style icon and live weekly quota percentage to the macOS menu bar.
- Uses the same shared `QuotaStore` as every widget window, so the menu-bar percentage and progress bar update together.

### Changed

- Shows the weekly reset countdown with a `d` unit whenever one or more days remain.
- Renames the balance unit from USD to localized points and rounds the displayed value to an integer.

### Install

- macOS: download `QuotaBubble-3.1.0-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
