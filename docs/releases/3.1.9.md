## Quota Bubble v3.1.9

This macOS release adds threshold-aware colors to the live system-capacity rows.

### Changed

- Shows available storage in red below 50 GB and in the first green progress-palette color otherwise.
- Shows available runtime memory in red above 11 GB and in the same green color otherwise.
- Keeps both rows gray when their system values cannot be read.
- Continues refreshing both capacity values once per second.

### Verified

- Added exact boundary tests for 50 GB of storage and 11 GB of runtime memory.
- Passed model, store, native snapshot, shell, and SwiftUI build tests.

### Install

- macOS: download `QuotaBubble-3.1.9-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
