## Quota Bubble v3.1.22

This release introduces the new Quota Bubble application icon across every product surface.

### Changed

- Replaced the previous letter-and-bars icon with a focused quota gauge bubble that represents remaining quota, reset timing, and the always-visible widget.
- Updated the macOS application and installer icon, Windows application and installer icon source, plugin icon, README branding, website header, favicon, and social artwork.
- Refreshed website cache keys so browsers load the new icon immediately.

### Verified

- The 1024px application, Windows source, and website icons are byte-identical.
- The macOS ICNS contains the same master icon at 1024px and valid representations down to 16px.
- macOS build tests and Windows native static tests pass.

### Install

- Windows: download `QuotaBubble-3.1.22-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.22-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
