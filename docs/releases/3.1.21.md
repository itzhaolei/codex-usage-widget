## Quota Bubble v3.1.21

This release restores automatic application startup after Windows in-app updates.

### Fixed

- The Windows installer now launches the newly installed Quota Bubble even when the in-app updater runs it in silent mode.
- After the update download finishes, the current process exits, installation completes, and the new version starts automatically.

### Verified

- Windows CI installs the package with the same silent mode used by the in-app updater.
- The workflow confirms that the installer starts Quota Bubble automatically and that the process remains running.
- The macOS installer is rebuilt from the same release tag for consistent cross-platform versioning.

### Install

- Windows: download `QuotaBubble-3.1.21-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.21-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
