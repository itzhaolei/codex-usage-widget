## Quota Bubble v3.1.14

This release ships the Windows updater connection fix from 3.1.13 with a corrected Windows build.

### Fixed

- Windows update requests use the signed-in user's system proxy credentials.
- If the GitHub API connection fails, the updater falls back to the GitHub Releases redirect and verifies the Windows installer directly.
- If both update sources are unavailable, an interactive check opens the official download page and shows a clear network, proxy, or system certificate message.

### Verified

- The Windows release workflow compiles the native app, installs the generated package, launches it, and uninstalls it on a Windows runner.

### Install

- Windows: download `QuotaBubble-3.1.14-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.14-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
