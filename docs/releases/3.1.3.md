## Quota Bubble v3.1.3

This macOS hotfix prevents quota synchronization from remaining paused after menu interaction on affected Macs. Windows remains on its existing release.

### Fixed

- Removes persistent menu suspension state and checks the current macOS run-loop mode independently on every timer tick.
- Prevents missing menu-end notifications from leaving weekly quota and the progress bar stuck at a stale value such as 100%.
- Keeps language menus selectable while resuming normal one-second synchronization automatically after menu tracking ends.
- Adds regression tests for default, common, and event-tracking run-loop modes.

### Install

- macOS: download `QuotaBubble-3.1.3-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
