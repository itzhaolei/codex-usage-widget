## Quota Bubble v3.1.5

This macOS hotfix fixes weekly quota values that could remain at 100% on some Macs or accounts. Windows remains on its existing release.

### Fixed

- Sends the official `ChatGPT-Account-Id` header with quota and reset-credit requests so the backend returns data for the currently selected account.
- Stops preserving a stale 100% quota indefinitely when the usage request fails. A short 15-second grace period still prevents transient network flicker.
- Accepts alternate usage field names and remaining-percentage payloads used by compatible Codex data sources.
- Keeps account identifiers out of the saved quota snapshot; they are used only in memory for request routing and fingerprinting.

### Verified

- Confirmed the native macOS service returned the current account's live weekly usage after the routing fix.
- Passed model, store, native snapshot, SwiftUI build, installer, and Universal architecture checks.

### Install

- macOS: download `QuotaBubble-3.1.5-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
