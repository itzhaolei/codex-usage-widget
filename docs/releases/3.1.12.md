## Quota Bubble v3.1.12

This release brings the Windows quota display in line with the macOS 5-hour and weekly quota behavior, and fixes Windows update checks when the latest release is macOS-only.

### Added

- Windows now shows a separate 5-hour quota block above the weekly quota when a 5-hour quota window is present.
- Windows shows the weekly reset date and weekday after the weekly reset countdown.

### Fixed

- Windows now treats a single quota window as the weekly quota instead of a 5-hour quota.
- Windows clears stale 5-hour quota data when the current account only reports a weekly quota.
- Windows tray status now uses the 5-hour remaining percentage when a 5-hour quota exists, and falls back to weekly quota otherwise.
- Windows update checks now scan recent releases for the newest `Windows-Setup.exe` asset, so macOS-only releases no longer produce a missing-installer error.

### Verified

- Added Windows static coverage for the quota-window mapping, separate 5-hour UI, tray percentage selection, and Windows updater asset selection.
- Passed Windows static tests and the macOS model, store, native snapshot, shell, and SwiftUI build tests.

### Install

- Windows: download `QuotaBubble-3.1.12-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.12-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
