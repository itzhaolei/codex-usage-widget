## Quota Bubble v3.1.13

This release makes Windows update checks resilient to GitHub API SSL and proxy failures.

### Fixed

- Windows update requests now use the signed-in user's system proxy credentials.
- If the GitHub API connection fails, the updater falls back to the GitHub Releases redirect and verifies the Windows installer directly.
- If both update sources are unavailable, an interactive check opens the official download page and explains that the network, proxy, or system certificate should be checked instead of showing the raw .NET SSL exception.

### Verified

- Added Windows static coverage for proxy credentials, the fallback release lookup, and the manual download fallback.
- The Windows release workflow compiles the native app, installs the generated package, launches it, and uninstalls it on a Windows runner.

### Install

- Windows: download `QuotaBubble-3.1.13-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.13-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
