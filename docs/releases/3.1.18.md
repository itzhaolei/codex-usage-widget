## Quota Bubble v3.1.18

This release keeps quota status available after the floating window is hidden and improves installation behavior on Windows.

### Changed

- Closing the main window now hides it on macOS and Windows while menu-bar or system-tray quota updates continue in the background.
- Quota Bubble exits only through the application or system-tray exit command.
- macOS now enforces one application instance and one quota window; the removed new-window command can no longer create duplicates.
- The Windows installer now always creates a Quota Bubble launch shortcut on the desktop.

### Verified

- The macOS app compiles successfully and keeps running after its single window is hidden.
- The Windows workflow compiles the native app, builds and installs the graphical package, verifies the desktop shortcut, launches the installed app, and uninstalls it.

### Install

- Windows: download `QuotaBubble-3.1.18-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.18-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
