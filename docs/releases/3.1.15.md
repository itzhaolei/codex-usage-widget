## Quota Bubble v3.1.15

This release aligns the Windows window with the macOS layout and adds native Windows system-capacity rows.

### Added

- Windows shows available C-drive space and available physical memory, refreshed every second.
- Capacity rows use the same healthy, warning, and unavailable colors as macOS.
- Title controls and account rows now use built-in vector icons that render consistently without font glyph dependencies.
- Added the five-color palette row below the weekly quota.

### Changed

- Matched macOS spacing across the header, quota blocks, percentages, reset-credit rows, cards, account rows, and version label.
- Metric cards use compact 47-point or two-line 59-point layouts and integer point balances.
- Reduced card opacity for a lighter glass appearance.

### Verified

- Passed Windows static and XAML syntax checks.
- Passed native Windows compilation, single-file publishing, application startup, graphical installer creation, silent installation, installed-app startup, and uninstall checks.

### Install

- Windows: download `QuotaBubble-3.1.15-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.15-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
