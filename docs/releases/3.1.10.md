## Quota Bubble v3.1.10

This macOS release adds support for showing a separate 5-hour quota window above the weekly quota when the signed-in account reports one.

### Added

- Shows a 5-hour quota block above the weekly quota for accounts with a 5-hour limit.
- Keeps the weekly-only layout unchanged for accounts that do not report a 5-hour limit.
- Shows the weekly reset weekday after the weekly reset timestamp.

### Fixed

- Clears stale cached 5-hour quota data when the native snapshot reports a weekly-only account.

### Verified

- Added store coverage for weekly-only, active 5-hour, exhausted 5-hour, and 5-hour removal states.
- Added model coverage to ensure the reset weekday is derived from the reset timestamp.
- Passed model, store, native snapshot, shell, and SwiftUI build tests.

### Install

- macOS: download `QuotaBubble-3.1.10-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
