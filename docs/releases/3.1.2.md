## Quota Bubble v3.1.2

This macOS hotfix restores continuous quota updates while retaining reliable language selection. Windows remains on its existing release.

### Fixed

- Restores one-second quota synchronization and progress-bar updates in the borderless macOS window.
- Keeps the refresh timer active in normal operation and pauses refresh work only while macOS is tracking an application menu.
- Immediately catches up after a menu closes, so language selection stays usable without leaving quota data stale.

### Install

- macOS: download `QuotaBubble-3.1.2-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
