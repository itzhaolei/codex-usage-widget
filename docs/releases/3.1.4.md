## Quota Bubble v3.1.4

This macOS update makes the weekly reset moment visible at a glance while preserving the compact widget layout. Windows remains on its existing release.

### Added

- Shows the exact weekly reset date immediately after the live countdown.
- Formats the reset date in local time as `MM-dd HH:mm:ss`.

### Changed

- Separates the countdown and exact date with a subtle divider.
- Uses smaller light-gray text for the exact date so the countdown remains visually primary.

### Install

- macOS: download `QuotaBubble-3.1.4-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
- Existing macOS users can also choose **Check for Updates** from the application menu.
