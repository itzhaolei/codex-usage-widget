## Quota Bubble v3.1.19

This release fixes the Windows in-app update download flow.

### Added

- Windows now displays a live download progress bar with percentage and downloaded/total size.
- When the server does not provide a total size, the dialog shows an indeterminate progress bar and the downloaded size.

### Fixed

- Removed the blocking “Downloading update” message box that prevented the download from starting until the user clicked OK.
- Prevented multiple update checks or progress dialogs from running at the same time.

### Verified

- The Windows workflow compiles the native application, builds the installer, installs it, verifies its desktop shortcut, launches it, and uninstalls it successfully.
- The macOS installer is rebuilt from the same release tag for consistent cross-platform versioning.

### Install

- Windows: download `QuotaBubble-3.1.19-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.19-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
