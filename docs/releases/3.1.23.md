## Quota Bubble v3.1.23

This release makes the current interface easy to see on white documentation pages and refreshes the macOS Dock icon after an application update.

### Fixed

- Replaced the transparent website and README preview with an opaque dark-mode render, including all localized README files and social artwork.
- macOS in-app updates now refresh Launch Services and the Dock icon cache before reopening Quota Bubble, so a newly installed application icon appears immediately.
- Full macOS installations now refresh the Dock after updating the pinned application entry.

### Verified

- The website and README preview files are byte-identical 660×614 opaque PNG images.
- Windows native static tests pass.
- macOS installer scripts pass shell syntax checks, and the Dock refresh behavior is covered by static assertions in the macOS test script.

### Install

- Windows: download `QuotaBubble-3.1.23-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.23-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
