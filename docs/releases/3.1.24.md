## Quota Bubble v3.1.24

This release prevents macOS from retaining an older Dock icon after an in-app update.

### Fixed

- macOS application and installer bundles now use a versioned icon resource filename, forcing Launch Services and Dock to resolve the icon from the current release.
- Quota Bubble explicitly applies its bundled icon when the application starts, so the running Dock item uses the installed icon even if the operating-system icon cache is stale.

### Verified

- The generated macOS application references `AppIcon-3.1.24.icns` in `Info.plist`.
- The packaged versioned icon is byte-identical to the repository's new application icon.
- macOS model, store, snapshot, SwiftUI build tests and Windows native static tests pass.

### Install

- Windows: download `QuotaBubble-3.1.24-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.24-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
