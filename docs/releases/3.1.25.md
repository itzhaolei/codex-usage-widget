## Quota Bubble v3.1.25

This release makes Windows update checks resilient to short-lived network, proxy, and TLS connection failures.

### Fixed

- Version checks automatically retry GitHub API, jsDelivr manifest, and GitHub Releases lookups with short backoff delays before showing an error.
- Each version lookup has a bounded timeout, preventing one unavailable endpoint from blocking the fallback sources for too long.
- The last successful release result is retained during the current application session and used if a later background lookup is interrupted.
- Installer downloads retry transient connection failures and reject incomplete files before starting the installer.

### Verified

- Windows static tests and native .NET compilation pass.
- The self-contained application launches successfully.
- The graphical installer builds, silently installs, removes legacy files, creates the desktop shortcut, and starts Quota Bubble automatically.

### Install

- Windows: download `QuotaBubble-3.1.25-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.25-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
