## Quota Bubble v3.1.16

This release fixes the Windows weekly reset countdown being truncated too early.

### Fixed

- The weekly reset countdown can now continue into the space to the right of the progress bar.
- The expanded countdown still preserves the exact reset date, divider, and reset weekday.

### Verified

- Passed Windows static coverage and XAML syntax validation.
- The Windows release workflow compiles, installs, launches, and uninstalls the generated package on a Windows runner.

### Install

- Windows: download `QuotaBubble-3.1.16-Windows-Setup.exe` and run the graphical installer.
- macOS: download `QuotaBubble-3.1.16-macOS-Installer.zip`, unzip it, and open `Install Quota Bubble.app`.
